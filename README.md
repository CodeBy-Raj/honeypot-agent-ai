# Scam Honeypot AI

A backend service for detecting and interacting with scam attempts using AI.

## Project Structure

- `src/index.js`: App entry point
- `src/app.js`: Express app config
- `src/routes/`: API routes
- `src/middleware/`: Middleware (Auth, etc.)
- `src/config/`: Configuration files
- `src/utils/`: Utility functions

## Getting Started

1. Install dependencies: `npm install`
2. Create `.env` file based on example
3. Run the server: `npm start` or `npm run dev`
